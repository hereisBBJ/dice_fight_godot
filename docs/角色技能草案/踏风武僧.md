# 踏风武僧（技能草案）

## 角色定位
- 稳定压迫型1v1连段角色，靠持续伤害维持连势。
- 不依赖高爆发，节奏断开则连势清空。

## 基础属性
- 生命值：85
- 初始 MP：20
- 最大 MP：60
- 最大护盾：20

## 核心机制：连势
- 上限2层。
- 攻击技能成功削减目标生命值时获得1层。
- 回合未造成伤害则清空全部连势。

## 被动：行云流水
- 攻击技能削减目标生命值时获得1层连势（上限2）。
- 回合未造成伤害则清空连势。
- 若本回合处于【追身步】状态，则不会失去连势。

## 技能
### 1. 试探连拳
- 类型：攻击
- 消耗：0 MP
- 骰子：1-3
- 效果：10伤害；若削减目标生命值，额外5伤害。

### 2. 震脉截击
- 类型：攻击/压制
- 消耗：10 MP
- 骰子：1-3，6
- 效果：15伤害。
- 至少1层连势时，消耗1层，使目标下回合第一次攻击技能伤害-10。
- 若削减目标生命值，回复10 MP。

### 3. 追身步
- 类型：防御/转接
- 消耗：10 MP
- 骰子：6，1-3
- 效果：10护盾。
- 有连势时，本回合不会失去连势，且下一个攻击技能+5伤害并回复5 MP。
- 效果在下次攻击技能后失效。

### 4. 千叠掌
- 类型：攻击
- 消耗：20 MP
- 骰子：6，6
- 效果：基础1次15伤害。
- 1层连势追加1次，2层连势共3次各15伤害。
- 结算时读取连势层数，使用后消耗1层连势。

## 实战思路
- 【试探连拳】稳步叠连势，【震脉截击】压制削弱敌方反扑。
- 【追身步】保节奏、转接爆发。
- 【千叠掌】高质量稳定输出，连势不断压力持续。

## 可复用点
- 连势机制、攻击削减判定、技能段数与资源联动、攻击削弱、护盾、技能效果延续。

## 需要新增
- 连势机制 effect（层数、获取、清空、消耗）
- 攻击削弱 effect（下回合生效）
- 技能效果延续/转接机制
